# Hands_On_Machine_Learning
 From Aurelien Geron


1. This repo, consists of **code learnings & theory Summarization** from the book "Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurelion Geron
2. Every chapter has its own notebook, which includes **short summaries and code implementation** provided in the book

## Requires Python 3.10.1
### Install the required libraries from requirements.txt
1. I have used "**pipreqsnb**" to generate the requirements.txt file
   1. In terminal , run `pipreqsnb .`

## What This Repository Can Do

### 🎯 Core ML Capabilities:
- Build price prediction models using regression techniques
- Create recommendation systems for product analysis
- Implement feature importance analysis
- Develop data visualization and insights
- Neural Networks and Deep Learning with TensorFlow/Keras

### 📋 New Demo Files:
- `CAPABILITIES_AND_LIMITATIONS.md` - Comprehensive explanation of what's possible vs. limitations
- `ML_Product_Analysis_Demo.ipynb` - Interactive Jupyter notebook demonstrating ML techniques
- `demo_ml_capabilities.py` - Runnable Python script showing ML capabilities

### 🚀 Quick Demo:
Run the ML capabilities demonstration:
```bash
python demo_ml_capabilities.py
```

### ❌ Important Limitations:
**This repository cannot:**
- Access external websites or shopping portals
- Perform web scraping or live data collection
- Get real-time pricing information
- Browse e-commerce sites

**However, it provides all the ML building blocks** needed to build such systems if you have access to product data!
